About DevOps

DevOps is a combination of Development (Dev) and Operations (Ops). It is a set of practices that helps teams build, test and deliver software faster and more reliably.

DevOps focuses on automation, collaboration, Continuous Integration (CI), Continuous Delivery (CD), monitoring and infrastructure management.
